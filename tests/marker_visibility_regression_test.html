Marker Visibility Regression Test

Test: MarkerEditHandler Updates Layer Visibility on LAYER_VISIBILITY_CHANGED Event

This test verifies that MarkerEditHandler properly subscribes to layer visibility changes and updates its internal reference when the layer visibility state changes.

Background: Previously, MarkerEditHandler stored a static reference to layerVisibility passed at construction time. When SidebarController toggled a layer off/on, this reference became stale and prevented marker placement after re-enabling the layer.

Fix: MarkerEditHandler now subscribes to LAYER_VISIBILITY_CHANGED events and updates its layerVisibility reference dynamically.
